## Validity
A run is VOID if < 90% of agent-ticks are error-free, or it stopped early (usage limit / error streak /
cost cap). VOID runs are reported, not replaced silently; a replacement uses world seed 1004+.

## Verdicts (frozen; n=3 per arm ⇒ descriptive, no p-values claimed)
- **Replication (sol-cued)**: REPRODUCED if ≥2/3 seeds reach adopted 9/9 by t50 AND run-mean eval ≥ F0 + 0.20.
  Else NOT REPRODUCED.
- **Cue (per model)**: CUE-DEPENDENT if cued ≥2/3 seeds adopted 9/9 and no-cue ≤1/3; CUE-INDEPENDENT if
  both ≥2/3; otherwise MIXED. Eval means reported for both arms.
- **Qwen capability**: CAN if ≥1/3 seeds have adopted ≥5 OR run-mean eval ≥ F0 + 0.20; else CANNOT (at 9B,
  this harness). If < 80% of its agent-ticks parse, the verdict is HARNESS/CAPABILITY FLOOR instead.
- Failure of the premise (grill Q2): NOT REPRODUCED in sol-cued ⇒ stop extensions, report that first.
